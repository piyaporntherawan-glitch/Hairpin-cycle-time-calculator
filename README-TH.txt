Cycle Time PWA — วิธีเผยแพร่ผ่าน GitHub Pages

1. สร้างบัญชีหรือเข้าสู่ระบบ https://github.com
2. กด New repository ตั้งชื่อ เช่น cycle-time-calculator และเลือก Public
3. อัปโหลดไฟล์ทั้ง 5 ไฟล์จากโฟลเดอร์นี้ไว้ที่ระดับบนสุดของ repository (อย่าอัปโหลด ZIP ทั้งก้อน)
4. เปิด Settings > Pages > Build and deployment > Source: Deploy from a branch
5. เลือก Branch: main และ Folder: /(root) แล้วกด Save
6. รอการเผยแพร่ แล้วเปิด URL ที่แสดงในหน้า Pages ซึ่งมักมีรูปแบบ https://USERNAME.github.io/cycle-time-calculator/
7. ส่งลิงก์ HTTPS ให้พนักงานผ่าน LINE ได้ทันที ไม่ต้องล็อกอิน
8. iPhone: เปิดลิงก์ใน Safari > แชร์ > เพิ่มไปยังหน้าจอโฮม
9. Android: เปิดลิงก์ใน Chrome > เมนู ⋮ > ติดตั้งแอป หรือ เพิ่มไปยังหน้าจอหลัก

หมายเหตุ: เว็บไซต์เป็นสาธารณะ ใครมีลิงก์เข้าถึงได้ ไม่มีฐานข้อมูลหรือระบบล็อกอิน
การคำนวณทำภายในอุปกรณ์ ไม่ส่งข้อมูลไปยังเซิร์ฟเวอร์
ฟังก์ชันออฟไลน์ทำงานหลังเข้าเว็บไซต์ผ่าน HTTPS และโหลดไฟล์สำเร็จครั้งแรก
หากอัปเดตแอปในอนาคต ให้เปลี่ยนชื่อ CACHE ใน sw.js เพื่อให้ไฟล์ใหม่ถูกติดตั้ง
